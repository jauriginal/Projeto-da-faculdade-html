# # Padaria Sonho Meu

Site em HTML e CSS de uma padaria fictícia, feito para a atividade da faculdade.

## Tema

Site de apresentação de uma padaria de bairro: produtos, promoções, contato
e uma página de login (só de exemplo, sem funcionar de verdade).

## Páginas

- index.html — página inicial, com produtos em destaque
- produtos.html — cardápio completo, promoções e formulário de contato
- login.html — página de login (usuário e senha de teste escritos na tela)
- style.css — estilo usado em todas as páginas

## Login de teste

## Como ver o site

Abra o arquivo index.html no navegador. Os 4 arquivos precisam estar
na mesma pasta.
